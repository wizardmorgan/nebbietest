=== ALIAS MUDLET ===
  c <spell> [tgt]     → cast (modalita' corrente)
  r <spell> [tgt]     → recall (stregone)
  m <spell> [tgt]     → mind (psi)
  mem <spell>         → memorize
  ncast/nrecall/nmind → cambia modalita' predefinita
  nclass +            → preset cast universale (multiclasse cast)
  nclass m c          → unisce slot di piu' classi
  nclass m            → imposta classe (salvata per profilo Mudlet)
  nclass              → elenca tutte le classi e slot q1-q9
  q1-q9 [tgt]         → slot rapidi della classe corrente
  nattrib             → sync attribute (gagged)
  nattrib on/off      → sync automatico ogni 90s
  nsetup              → avvia HUD (non cambia il prompt)
  ngui / nhud         → mostra/nasconde HUD
  inv / eq            → comandi MUD nativi (non aliasati)
  nloot               → look, poi corp/2.corp/… + pile/2.pile/…
  nloot on/off        → loot auto dopo kill mob (exp reale)
