# Nebbie — Edit Portal (export solo UI)

Snapshot **solo portale** per pubblicare su `NebbieArcane/edit-portal` via GitHub Desktop.

Questo branch (`publish/edit-portal-ui`) sul fork `wizardmorgan/nebbietest` contiene **solo** i file del portale in root (non il mud Server).

## Download ZIP

GitHub → branch `publish/edit-portal-ui` → Code → **Download ZIP**

Oppure: https://github.com/wizardmorgan/nebbietest/archive/refs/heads/publish/edit-portal-ui.zip

## Import in NebbieArcane/edit-portal

1. GitHub Desktop → Clone `NebbieArcane/edit-portal`
2. Estrai/copia il contenuto di questo ZIP **nella root** del clone
3. Commit + Push

Vedi `docs/edit-portal-publish-desktop.md`.
